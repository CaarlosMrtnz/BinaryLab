En una representación de **punto fijo** se establece de antemano cuántos bits corresponden a la parte entera y cuántos a la parte fraccionaria; el separador no se guarda como un carácter en la secuencia binaria.

Ejemplo: un patrón de 16 bits con **8 bits de parte entera y 8 de fracción**.

```text
Bits almacenados: 0110010100010101
Interpretación:   01100101.00010101₂
Parte entera:     01100101₂ = 101₁₀
Parte fracc.:     00010101₂ = 2⁻⁴ + 2⁻⁶ + 2⁻⁸
                               = 0,08203125₁₀
Total:            101,08203125₁₀
```

Cuantos más bits se reserven para fracción, menor será el escalón de representación; cuantos más se reserven para parte entera, mayor será el rango de magnitudes. Un formato fijo puede ser ineficaz si deben almacenarse simultáneamente cantidades extremadamente grandes y extremadamente pequeñas.

**Precisión:** El ejemplo se interpreta **sin signo**. La representación de negativos en punto fijo depende de la convención escogida; no deducir automáticamente la codificación del signo a partir de este ejemplo.

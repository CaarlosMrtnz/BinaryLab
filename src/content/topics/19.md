El punto fijo reparte el presupuesto de bits entre parte entera y parte fraccionaria. Esto limita su flexibilidad cuando se necesitan simultáneamente valores de magnitudes muy distintas, como algunas constantes físicas. El **punto flotante** se inspira en la notación científica: combina un signo, un **exponente** que modifica la escala y un **significando**. En IEEE 754 binario, el campo de fracción almacenado no debe confundirse con el significando: para números normales finitos, este se interpreta como `1.f`; para subnormales, como `0.f`. Estas expresiones no se aplican a ceros, infinitos ni NaN.

La idea general es análoga a `3,1536 × 10⁷`, pero se utiliza una potencia de **base 2**. No debe confundirse el formato de notación científica escrito en un libro con el formato exacto de bits de IEEE 754.

Para una representación binaria normalizada habitual:

```text
Número = (−1)^signo × 1.fracción_binaria × 2^exponente_real
```

**Precisión:** La escritura normalizada `1.x... × 2^e` describe directamente el valor de un número **normal** en IEEE 754. También puede representarse mediante `0.1... × 2^(e+1)`, ajustando el exponente.

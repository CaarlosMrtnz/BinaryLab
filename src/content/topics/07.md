Procedimiento que debe mostrarse en pasos:

1. Dividir el entero no negativo entre 2.
2. Registrar el cociente **entero** y el resto (`0` o `1`).
3. Repetir la división sobre el cociente hasta obtener cero.
4. Leer los restos **desde la última división hacia la primera**.
5. Verificar mediante la suma de potencias de dos.

Ejemplo: `108₁₀`.

| Dividendo | Cociente `÷ 2` | Resto |
| --------: | -------------: | ----: |
|       108 |             54 |     0 |
|        54 |             27 |     0 |
|        27 |             13 |     1 |
|        13 |              6 |     1 |
|         6 |              3 |     0 |
|         3 |              1 |     1 |
|         1 |              0 |     1 |

Restos leídos de abajo arriba: `1101100₂`. Comprobación: `64 + 32 + 8 + 4 = 108`.

Otros ejemplos:

```text
95₁₀ = 1011111₂ = 01011111₂ en 8 bits
29₁₀ = 11101₂   = 00011101₂ en 8 bits
```

El número `0₁₀` se representa como `0₂` (no como una cadena vacía). Para otros sistemas de destino, el procedimiento se generaliza dividiendo sucesivamente entre la base `B`; para restos mayores o iguales que 10 en hexadecimal se escriben `A`–`F`.

Un ordenador almacena **códigos** para representar caracteres; una fuente y un sistema de visualización presentan esos códigos como grafías. ASCII y Unicode permiten establecer correspondencias entre números y caracteres. Esta idea se relaciona directamente con las conversiones decimal ↔ binario ↔ hexadecimal.

Ejemplo aclarado con la palabra `hola` (minúscula):

| Carácter | Código decimal ASCII | Hexadecimal | Binario en un byte |
| -------- | -------------------: | ----------- | ------------------ |
| h        |                  104 | 68          | `01101000`         |
| o        |                  111 | 6F          | `01101111`         |
| l        |                  108 | 6C          | `01101100`         |
| a        |                   97 | 61          | `01100001`         |

**Precisión:** En ASCII, el código 72 corresponde a `H` mayúscula y 104 a `h` minúscula.

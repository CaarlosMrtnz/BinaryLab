Una imagen de tipo **mapa de bits** se compone de píxeles. En el modelo **RGB**, cada píxel se describe con tres componentes: rojo (R), verde (G) y azul (B). En el caso de **8 bits por componente**, cada componente toma valores entre 0 y 255, y un píxel RGB sin alfa ocupa **24 bits = 3 bytes** antes de considerar información adicional o compresión.

Ejemplos:

```text
Rojo:     R=255, G=0,   B=0   → FF 00 00 (hex)
Amarillo: R=255, G=255, B=0   → FF FF 00 (hex)
Blanco:   R=255, G=255, B=255 → FF FF FF (hex)
Negro:    R=0,   G=0,   B=0   → 00 00 00 (hex)
```

El espacio de colores RGB de 8 bits por componente tiene `256³ = 16.777.216` combinaciones. Para una imagen RGB sin comprimir ni metadatos:

```text
Tamaño en bytes = ancho_en_píxeles × alto_en_píxeles × 3
```

Ejemplo con unidades precisas:

```text
1280 × 1024 × 3 = 3.932.160 bytes
                 = 3,93216 MB (decimales)
                 = 3,75 MiB (binarios)
```

**Precisión:** El valor **3,75** corresponde a **MiB** y no a MB decimales. El archivo de imagen real puede contener cabeceras, metadatos, compresión, canal alfa, padding y otras estructuras; la fórmula anterior describe un modelo simple de datos RGB sin comprimir.

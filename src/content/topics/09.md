Las conversiones entre las cuatro bases —binario, octal, decimal y hexadecimal— pueden hacerse en cualquier dirección. Cuando no exista una equivalencia directa sencilla, se puede recurrir al valor posicional o utilizar el binario como base intermedia. Los procedimientos habituales son:

| Origen → destino      | Procedimiento matemático                                      |
| --------------------- | ------------------------------------------------------------- |
| Binario → decimal     | Suma de potencias de dos                                      |
| Decimal → binario     | Divisiones sucesivas entre dos                                |
| Octal → decimal       | Descomposición en potencias de ocho                           |
| Hexadecimal → decimal | Descomposición en potencias de dieciséis                      |
| Binario ↔ octal       | Grupos de tres bits                                           |
| Binario ↔ hexadecimal | Grupos de cuatro bits                                         |
| Decimal → octal/hex   | Divisiones sucesivas entre la base de destino                 |
| Octal ↔ hexadecimal   | Conversión intermedia exacta (habitualmente mediante binario) |

**Reglas de representación:** diferenciar `secuencia de entrada`, `valor numérico`, `base`, `ancho` y `modo de interpretación`. Los cambios de base de números enteros son exactos: no requieren redondeos. Si existe un límite de longitud, debe distinguirse entre valor matemático y representación truncada.

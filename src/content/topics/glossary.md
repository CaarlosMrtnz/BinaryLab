| Término                | Definición breve                                                                          |
| ---------------------- | ----------------------------------------------------------------------------------------- |
| Base                   | Número de símbolos diferentes y factor posicional de un sistema de numeración.            |
| Grafía                 | Símbolo que representa un dígito o valor.                                                 |
| Bit                    | Dígito binario, 0 o 1.                                                                    |
| Byte                   | Conjunto de ocho bits.                                                                    |
| MSB / LSB              | Bit más significativo / menos significativo.                                              |
| Peso                   | Contribución dada por una potencia de la base.                                            |
| Acarreo / préstamo     | Propagación de una unidad a la columna superior / solicitud de una unidad de esa columna. |
| Sin signo              | Interpretación con valores enteros no negativos.                                          |
| Magnitud y signo       | Bit de signo más bits que representan la magnitud.                                        |
| C1                     | Representación de negativos invirtiendo todos los bits de la magnitud con ancho fijo.     |
| C2                     | Representación de negativos invirtiendo y sumando uno con ancho fijo.                     |
| Overflow               | Resultado matemático que no cabe en el rango disponible.                                  |
| BCD 8421               | Codificación de cada cifra decimal en cuatro bits.                                        |
| Punto fijo             | Posición predefinida del separador entre parte entera y fraccionaria.                     |
| Punto flotante         | Codificación mediante signo, exponente y significando.                                    |
| Sesgo (bias)           | Constante que se suma al exponente real para almacenarlo sin signo.                       |
| Significando           | Parte que determina los dígitos significativos de un número flotante.                     |
| Subnormal              | Patrón IEEE con exponente cero y fracción distinta de cero.                               |
| NaN                    | Patrón especial IEEE que indica un resultado no numérico.                                 |
| ASCII / Unicode        | Sistema de códigos para caracteres / repertorio universal de puntos de código.            |
| RGB                    | Modelo de color con componentes rojo, verde y azul.                                       |
| Píxel                  | Unidad de información de color de una imagen raster.                                      |
| Muestreo               | Captura de valores de una señal en instantes separados.                                   |
| Profundidad de bits    | Cantidad de bits por muestra o componente.                                                |
| Compresión sin pérdida | Reducción de tamaño que permite reconstruir exactamente los datos.                        |

1. Identificar el patrón binario y su ancho.
2. Numerar las posiciones comenzando en cero por la derecha.
3. Multiplicar cada bit por su potencia de dos.
4. Sumar las contribuciones activas.

Ejemplos:

```text
01101100₂ = 2⁶ + 2⁵ + 2³ + 2²
           = 64 + 32 + 8 + 4 = 108₁₀

10010010₂ = 2⁷ + 2⁴ + 2¹
           = 128 + 16 + 2 = 146₁₀

10010101₂ = 2⁷ + 2⁴ + 2² + 2⁰
           = 128 + 16 + 4 + 1 = 149₁₀
```
